# Zyntrixly logo refinement tests

This is an isolated design-test folder on the `logo-refinement-test` branch. Production assets and application references are untouched.

## Concepts

- **`v2-original-preserving.svg`** — the current refinement candidate. It preserves the original three-piece Z geometry, narrow diagonal connector, single central node, and double-layer obsidian enclosure. The work is limited to SVG semantics, predictable rendering, and a smoother, more restrained silver finish.
- **`v1-identity-redesign.svg`** — the earlier exploratory redesign. It changes the silhouette and is retained only as a historical comparison, not as the recommended direction.

The production logo at the repository root remains unchanged. Neither concept has been integrated into the application.
